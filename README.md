## Что это за сайт

Магазин домашней одежды: главная с первым экраном, пятью секциями каталога
и фильтрами, **141 страница товара**, каталог **17 авторских принтов** для
нанесения, корзина с оформлением заказа и страницы благодарности. Реальный
контент, реальная структура каталога — но заказ по задумке остаётся в браузере:
отправки на сервер нет, и на странице благодарности это честно написано.

Проект собран вручную: **49 674 строки разметки**, **6 115 строк CSS
в 26 файлах**, **8 453 строки JavaScript в 23 модулях** — и ни одного
фреймворка, ни одной зависимости, ни одного шага сборки.

<br />

## Ключевые решения

**Каталог, который живёт в одном файле данных.** Все 141 товар — это записи
в `assets/js/data.js`: название, состав, цена (от 290 до 14 199 ₽), метки типа,
возраста и цвета, размеры, описание, характеристики и адрес страницы. Карточки,
фильтры, сортировка, страницы пагинации и стрелки «соседний товар» читают
одни и те же данные, поэтому добавить товар — значит дописать запись, а не
править разметку в пяти местах.

**Страницы товаров по трём образцам.** Женская, мужская и «другие товары» —
три типа разметки, скопированные, а не сочинённые заново: у женских и мужских
есть размеры, блок принта и строка состава, у подушек и халатов — две колонки
по центру и никаких размеров. Вид страницы задаёт `data-section`, а не секция
каталога, поэтому «Новая коллекция» может быть и женской, и мужской.

**Корзина и оформление целиком на клиенте.** Позиции, количество и выбранный
размер лежат в `localStorage`; корзина переживает перезагрузку и битые данные.
Оформление проверяет имя и телефон (обязательные) и почту (по желанию), пишет
заказ с номером вида `20261117154032-4821` и уводит на страницу благодарности,
которая этот заказ и показывает.

**Печать принтов считается по правилу владельца.** Один бесплатный принт
за каждые 15 000 ₽ товаров: два — от 30 000 ₽, три — от 45 000 ₽. Принты
не входят в сумму товаров (иначе сами себе приближали бы порог), бесплатные
раздаются по порядку позиций, а в карточке видно «бесплатно 1 из 18».
Свой макет печатается по согласованию и денег не добавляет.

**Фильтры без перезагрузки.** Тип изделия, возраст, палитра цветов, сортировка
и пагинация работают на одном наборе данных: состояние живёт в памяти,
чипсы и кружки переключаются с `aria-pressed`, результаты пересобираются
без обращения к серверу.

**Модальные окна с ловушкой фокуса.** Размер, корзина и выбор окна —
общий блок `modal`: открытие по атрибуту, закрытие по Escape, затемнению
и крестику, удержание фокуса внутри, возврат фокуса на кнопку открытия
и блокировка прокрутки страницы, пока окно открыто.

**Декор, который не мешает.** На первом экране — разлетающиеся звёзды
(пять секунд, один раз за загрузку), в подвале — звёздный дождь по появлению
в кадре. Оба сценария уважают `prefers-reduced-motion` и отключаются для тех,
кому движение мешает.

**Доступность как часть вёрстки.** Ссылка «Перейти к содержимому» первой
в теле каждой страницы, видимый `:focus-visible`, `role="dialog"` и
`aria-modal`, `role="alert"` у ошибок формы, `aria-invalid`, `aria-live`
у счётчика корзины, подписи у всех полей и `alt` у всех изображений.

**Адаптив от 320 px без горизонтальной прокрутки.** Точки перелома — `480`,
`768`, `1024` и `1280` px — и собственные значения под каждую: каталог идёт
от одной колонки до четырёх, страница товара из трёх колонок становится
одной, меню на мобильном уезжает в наложение, а фото товара — по центру.

## Палитра и типографика

Палитра вынесена в токены `assets/css/base/variables.css` — в разметке
нет ни одного «своего» цвета:

| Токен | Значение | Где работает |
| ----- | -------- | ------------ |
| `--color-dark` | `#4c4c4c` | Основной текст, тёмные кнопки при наведении |
| `--color-pink` | `#cd74a2` | Названия товаров, кнопка «В корзину» |
| `--color-pink-light` | `#f4d9e8` | Фоны секций женской коллекции |
| `--color-blue` | `#93b3d6` | Кнопки мужской коллекции, первый экран |
| `--color-blue-light` | `#dae2e4` | Подвал главной, секции |
| `--color-grey-blue` | `#dfeaee` | Блок обратной связи |
| `--color-beige` | `#dbcbb2` | Рамки, разделители, плашка цены |
| `--color-beige-light` | `#e9e2d0` | Фоны секций «Других товаров» |
| `--color-yellow` | `#fff4a4` | Акцент блока принта |
| `--color-white` | `#ffffff` | Фоны карточек и окон |

Типографика — одна гарнитура с двумя ролями: **Roboto Slab 400/700**
(Google Fonts, `display=swap`). Заголовки набираются ею же, поэтому
у сайта нет «второго голоса» — только размеры и цвет.

## Технический стек

| Слой | Решение |
| ---- | ------- |
| Разметка | Семантические `header` / `main` / `section` / `article`, `lang="ru"`, уникальные `title` и `description` |
| Стили | CSS3, БЭМ-нейминг, токены в переменных, Flexbox, Grid, `@keyframes`, `@media` |
| Скрипты | Vanilla JS, ES-модули (`import`/`export`), без jQuery и сборщиков |
| Данные | Один файл каталога + модуль принтов; состояние — в `localStorage` |
| Изображения | WebP (181 файл), ленивая загрузка карточек, `width`/`height` у всех `<img>` |
| Шрифты | Google Fonts: Roboto Slab 400/700, кириллица, `swap` |
| Иконки | SVG: корзина, стрелки, крестик, соцсети, кольца разделителей |
| Хостинг | GitHub Pages (ветка `main`, `.nojekyll`) |

## Как проверено

Проект обвешан проверками: **10 102 утверждения в 176 файлах**, которые
запускаются `node` без браузера и без зависимостей — от размеров картинок
до цепочек стрелок между товарами (одна эта проверка — 1 937 утверждений).
Отдельно — обход всех страниц в браузере.

| Ширина | Страниц | Горизонтальная прокрутка | Битые картинки | Ошибки в консоли |
| ------ | ------- | ------------------------ | -------------- | ---------------- |
| 320 px | 145 | 0 | 0 | 0 |
| 1440 px | 145 | 0 | 0 | 0 |

Дополнительно проверено поведением, а не только видом:

* **Ссылки и якоря** — 145 страниц, 0 битых `href`, `src` и якорей, включая
  ссылку «Перейти к содержимому» на каждой странице.

* **Корзина** — добавление, изменение количества, удаление, счётчик в шапке,
  сохранение между перезагрузками, устойчивость к битому `localStorage`.

* **Оформление заказа** — пустая форма даёт две ошибки и фокус на имени,
  заполненная пишет заказ, очищает корзину и открывает страницу благодарности
  (в том числе со страницы товара, а не только с главной).

* **Принты** — 18 принтов при товарах на 24 000 ₽ дают ровно один бесплатный,
  строка «Печать «ПРИНТ»» считает платные единицы, страница благодарности
  повторяет итог корзины.

* **Клавиатура** — Tab попадает на ссылку пропуска и разворачивает её поверх
  страницы, Enter уводит фокус в содержимое, Escape закрывает окна, фокус
  возвращается на кнопку открытия.

## Оптимизация

* **Вся графика переведена в WebP** — 181 файл вместо PNG и JPEG.
  Папка `assets/images` похудела со 140 МБ до **11 МБ**, самая тяжёлая
  картинка — 279 КБ (превью для соцсетей), фон первого экрана — 71 КБ.

* **Главная страница: 59 МБ → 1,39 МБ**, запросов 138 → 73. Фотографии
  товаров отдаются в исходном разрешении (высота до 1 536 px — запас на
  экраны с двойной плотностью), квадраты принтов и «других товаров» —
  700×700 при показе не крупнее 350 px.

* **Ленивая загрузка каталога** — `loading="lazy"` и `decoding="async"`
  у 72 карточек: до прокрутки грузится 17 изображений вместо 83.

* **Нет скачков раскладки** — у каждого изображения стоит `width`/`height`,
  а размеры в данных сверяются с файлами автоматической проверкой.

* **Один шрифт вместо набора** — два начертания Roboto Slab с `display=swap`
  и `preconnect` к Google Fonts: текст виден сразу, подмена не мигает.

## Запуск

Сборка не нужна: ни npm, ни транспиляции, ни препроцессоров. Достаточно
клонировать и поднять локальный сервер:

```bash
git clone https://github.com/Artem02031980/CozyPajamasStore.git
cd CozyPajamasStore
python -m http.server 8000
```

Затем `http://127.0.0.1:8000/`.

Сервер обязателен: проект на ES-модулях, а по `file://` браузер их
не загружает (CORS). Любой свободный порт подойдёт — главное, чтобы
страница открывалась по `http://`.
