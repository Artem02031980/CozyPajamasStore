# CozyPajamasStore — Магазин уютных пижам

Учебный проект: вёрстка сайта интернет-магазина пижам по готовому дизайн-макету.

**Стек:** чистый HTML, CSS и JavaScript. Без сборщиков, без фреймворков, без PHP.
Корзина и оформление заказа работают только на JavaScript, с сохранением в `localStorage`.
При нажатии «купить» открывается страница `thanks.html` с благодарностью за покупку.

## Структура проекта

```

├── index.html              # вся страница целиком (все секции макета)
├── thanks.html             # «Спасибо за покупку!»
├── README.md               # этот файл
├── .gitignore
│
├── assets/
│   ├── css/
│   │   ├── base/

│   │   │   ├── variables.css    # ВСЯ дизайн-система: цвета, шрифты, отступы, радиусы, z-index

│   │   ├── components/

│   │   │   ├── hero.css         # баннер: фон-небо, облака, заголовок, CTA
│   │   │   ├── product-card.css # карточка товара: фото, название, состав, цена
│   │   │   ├── filters.css      # чипсы фильтров, палитра цветов, диапазоны цен
│   │   │   ├── pagination.css
│   │   │   ├── modal.css        # общий оверлей + карточка товара + модалка корзины
│   │   │   ├── cart.css         # список позиций, суммы, оформление заказа
│   │   │   ├── print-service.css
│   │   │   ├── pillows.css      # карусель подушек
│   │   │   ├── feedback.css     # блок «Отключитесь от всех тревог» + форма
│   │   │   └── footer.css
│   │   ├── pages/
│   │   │   └── thanks.css
│   │   ├── utilities.css    # .visually-hidden, .is-hidden, .no-scroll, анимации (искры, бабочки)

│   │
│   ├── js/
│   │   ├── data.js          # каталог: id, название, состав, размеры, цены, путь к фото, теги фильтров

│   │   ├── filters.js       # фильтрация, сортировка, пагинация
│   │   ├── modal.js         # открытие/закрытие, ESC, клик по фону, focus-trap
│   │   ├── checkout.js      # «Купить в один клик», оформление, переход на thanks.html
│   │   ├── thanks.js        # читает заказ из localStorage и показывает его на thanks.html
│   │   ├── feedback.js      # форма «Задайте вопрос»
│   │   ├── utils.js         # formatPrice(), делегирование событий, debounce
│   │   └── script.js        # точка входа: импортирует модули, навешивает обработчики

│   └── images/
│       ├── hero/            # hero-bg.jpg, hero-girl.png, облака, замок, декор
│       ├── products/
│       │   ├── new/         # 6 товаров «Новой коллекции»
│       │   ├── women/       # женская коллекция
│       │   ├── men/         # мужская коллекция

│       ├── print/           # футболка «Дай пять» для блока «Принт»
│       ├── pillows/         # 4 подушки
│       ├── shared/          # фоновые текстуры секций (бежевая, голубая, розовая)
│       └── icons/           # корзина, стрелки ‹ ›, крестик, инстаграм, вк, тг, звёздочки, favicon.svg
```

## Чего в проекте нет

любые `.php` и папка `api/` (заказ имитируется, переход на `thanks.html` делает JS);
`scss/`, `dist/`, `node_modules/`, сборка; `assets/fonts/` (шрифты подключаются ссылкой);
`assets/js/vendor/` (только ванильный JS); `404.html`.
